# 照会済みの名前の控え

MistTrack に**代金を払って得た**名前の置き場です。

本番の置き場は Railway の永続ディスク1箇所だけで、**ボリュームを作り直すと消えます**。
消えると同じアドレスにまた代金がかかるため、ここに控えを置きます。
（自前DB `manual-labels` に git 書き出しがあるのと同じ考え方です）

## 保存のしかた

1. 管理画面を開く
   `https://delightful-insight-production-00a3.up.railway.app/api/admin/labels`
2. **「保存する（JSONで書き出し）」** を押す → `label-cache.json` が落ちてくる
3. そのファイルを **このフォルダ** に置く（名前はそのままで構いません）
4. コミットする

```bash
bash backup/commit.sh
```

日付入りの名前に変えて、コミットとプッシュまで行います。

## 戻すしかた

1. 同じ管理画面の下の枠に、控えたファイルの中身をそのまま貼る
2. **「読み込む」** を押す

★ いまある名前は上書きしません。足りない分だけ足します。

## 中身について

```
名前あり  例 "0x28c6…": {"name":"Binance 14","type":"exchange"}
名前なし  例 "0xabcd…": {"name":"","type":""}
```

★**「名前なし」も控えます。** これが「引いたが名前は無かった」の記録で、
二度払わないために要ります。取引所の入金アドレスはほとんど名前が付かないため、
ここが失われると同じアドレスに何度も代金を払うことになります。

## 頻度の目安

新しく調査が走った日の終わりか、**広告期間中は週に1回**。
起動ログの「照会済みの名前 ○件」が増えていたら保存どきです。
